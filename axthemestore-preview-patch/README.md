# AxThemeStore IosSignal preview patch

Replace these files in `android_packages_apps_AxThemeStore/res/drawable/`:

- preview_iossignal_1.xml
- preview_iossignal_2.xml
- preview_iossignal_3.xml
- preview_iossignal_4.xml

They use compact filled geometry matching the fixed 17x12 signal icon instead of the old 25dp zero-length stroke previews.
