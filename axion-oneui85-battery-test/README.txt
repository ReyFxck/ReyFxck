One UI 8.5 battery test overlay for AxionOS.

Package:
com.android.systemui.battery.oneui85

This is a test RRO only. It relies on AxionOS SystemUI ThemedBatteryDrawable for:
- live battery level
- charging state
- low battery state
- power-save state
- light/dark tint
- centered battery percentage

Designed as a slimmer, smaller pill than the existing One UI 7 battery.
